# Request endpoint (Google Apps Script)

`Code.gs` is generated by `tools/make_apps_script.py` from `tools/forms.py`. Re-run it whenever programmes or offers change, then paste the new file into the Apps Script project.

## Deploy (about 10 minutes, from the Tyros Google account)
1. **Google Sheet**: create an empty Sheet named "Tyros leads". Copy its id (the long string in its URL).
2. **Programme PDF**: upload the programme PDF to Google Drive (private). Copy its file id from the share link.
3. **Apps Script**: script.google.com > New project > paste `Code.gs`.
4. **Script properties** (Project settings > Script properties):
   - `SHEET_ID` = the Sheet id
   - `PDF_FILE_ID_DEFAULT` = the PDF file id (optional per programme: `PDF_FILE_ID_dora-awareness`, `PDF_FILE_ID_ai-literacy`, `PDF_FILE_ID_manager-recruiter`, `PDF_FILE_ID_specialist-talent`, `PDF_FILE_ID_business-development`, `PDF_FILE_ID_client-relationships`)
   - `NOTIFY_TO` = internal recipient (default `contact@tyros-group.com`)
5. Run `authorizeOnce` once from the editor and accept the Sheets, Mail and Drive permissions. It creates the `Leads` tab.
6. **Deploy** > New deployment > type *Web app* > Execute as **Me**, Who has access **Anyone** > Deploy. Copy the `/exec` URL.
7. In `assets/request.js`, replace `https://script.google.com/macros/s/__DEPLOY_ID__/exec` with that URL, commit, publish.
8. Send one test request per journey and check: row in `Leads`, internal e-mail, acknowledgement (with PDF for a programme request).

The `/exec` URL is public by nature (like any form endpoint) and carries no secret. All validation is repeated on the server: honeypot, minimum fill time (4 s), maximum age (24 h), per-field whitelists and length caps, 3 requests per e-mail per hour, and spreadsheet formula neutralisation.

## What is recorded
Reference, UTC time, journey, language, offer/programme, intent, name, company, email, journey-specific fields, message, source page, source URL, status, acknowledgement status, PDF status.

## Mail quota
Apps Script allows about 100 recipients per day on a free Google account and about 1,500 on Google Workspace. Each request sends two mails (visitor + internal).
