# Request endpoint (Google Apps Script)

`Code.gs` is generated by `tools/make_apps_script.py` from `tools/forms.py`. Re-run it when programmes or offers change.

## What it does
Receives the site forms, validates them on the server, writes one row per request in a Google Sheet, e-mails Tyros the request with its context, and sends the visitor a plain acknowledgement of receipt. No document is ever sent automatically: for a programme request, Tyros identifies the person, then sends the programme by hand (the internal e-mail says so).

## Deploy (about 10 minutes, from the Tyros Google account)
1. **Sheet**: create an empty Google Sheet "Tyros leads". Copy its id (the long string in its URL, between `/d/` and `/edit`).
2. **Apps Script**: script.google.com > New project. Replace the content of `Code.gs` with the file `tools/apps-script/Code.gs` from the repository.
3. **Properties**: Project settings > Script properties > add `SHEET_ID` = the Sheet id. Optional: `NOTIFY_TO` (default contact@tyros-group.com).
4. **Permissions**: in the editor choose `authorizeOnce` > Run > accept Sheets and Mail access. It creates the `Leads` tab.
5. **Deploy**: Deploy > New deployment > type Web app > Execute as: Me > Who has access: Anyone > Deploy. Copy the URL ending in `/exec`.
6. **Real test**: choose `selfTest` > Run. It posts one request per journey to the live URL, then lists what to verify (Sheet rows, internal mails, acknowledgements). Delete the `[TEST]` rows afterwards.
7. **Site**: give the `/exec` URL to Claude (or replace `__DEPLOY_ID__` in `assets/request.js`), then submit one request from the real site in FR and one in EN.

## Checks done on the server
Honeypot (silent success, nothing stored), minimum fill time 4 s, maximum age 24 h, fixed lists for every choice, length caps, 3 requests per e-mail per hour and 120 per hour overall, spreadsheet formula neutralisation, unknown offers dropped.

## Sheet columns
Reference, UTC time, journey, language, offer/programme, intent, name, company, email, role, location, timing, topic, deadline, participants, format, period, message, source page, source URL, status, acknowledgement, "Programme sent (manual)" (to fill by hand).

## Quota
About 100 recipients/day on a free Google account, 1,500 on Workspace. Each request sends two mails.

## CV upload
Not provided: no journey in the site asks for a CV. If you want it, decide first where files are stored, who can open them, for how long, and what the privacy policy says (see `design-system/DECISIONS-CONFIDENTIALITE.md`).
