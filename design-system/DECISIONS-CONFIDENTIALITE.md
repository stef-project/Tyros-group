# Politique de confidentialité : décisions à prendre

Le formulaire unique ne conserve rien en dehors de votre messagerie : pas de tableur, pas de CV, pas de réponse automatique.

À décider :
1. **Durée de conservation des messages reçus** dans la messagerie Tyros. Aucune durée n'est affichée. Un commentaire « décision requise » est dans la page.
2. **Sessions Tyros Academy** : le texte existant (avant la refonte) dit 3 ans à compter de la session. À confirmer ou modifier.
3. **Accès** à la boîte qui reçoit les demandes (vous seule, ou d'autres personnes).
4. **Prestataires** : Google (messagerie, Apps Script) reçoit les messages, GitHub héberge le site, Google Tag Manager est présent. À lister, avec les transferts hors Royaume-Uni et UE. Si Google Analytics est actif, prévoir un bandeau de consentement.
5. **Fondement légal** et **droit de réclamation** (ICO au Royaume-Uni, CNIL pour les résidents français) : à faire valider, idéalement par un juriste.
6. **Candidatures spontanées** : plus de dépôt de CV sur le site. Les candidats écrivent via le formulaire ; s'ils joignent un CV par e-mail, la même durée s'applique. À préciser si vous voulez une règle distincte.
